# Process overview

Sword Art Online first drew me to computing. I wanted After Aincrad, a history course set in 2035, to make its events understandable to newcomers. Before building content, I asked Codex to research OpenAI and Anthropic guidance, studies of instruction files and practitioner methods. The sources, report, candidate instructions and trial results are saved in [the harness research folder](docs/harness-research/README.md). My starting point was the Crit 5 instructions that Claude had adapted during setup ([0b50b24](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/0b50b24)).

The “rules” we compared were the directions in CLAUDE.md: which files the agent should read, when it should plan and how it should check its work. Codex drafted revisions from the research and compared them with the original on small repository tasks. Across 18 scored runs, each pair started from matching project copies; only the CLAUDE.md version differed. The model and settings stayed fixed. We kept browser checks, added independent review, and told the agent to plan uncertain changes and read only relevant files. We also removed duplicate build instructions. The chosen practices went into CLAUDE.md, which I required the agent to follow. AGENTS.md directs Codex to read it before editing ([2b885c8](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/2b885c8)).

The evaluation checked behaviour as well as code: preserving existing edits, leaving files untouched on read-only tasks, and reporting which checks actually ran. We fixed these criteria before comparing outputs and kept the judging code outside the trial copies, checking it for changes. All 18 results passed its automatic checks. A separate agent reviewed outputs without their version labels and spotted a false pass: text that looked like a link counted as a link even though nothing was clickable. The main agent reproduced it, then replaced the text search with a check of real HTML links. That passed 31 valid and invalid cases. Reviewing the checks themselves became part of deciding whether to accept the work ([785b1ce](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/785b1ce)).

Implementation followed the same loop: research a choice, plan it, build a small part, compare and review the result, then update the next task’s instructions. Agents owned separate teaching, source, interface and slide files; the main agent checked their findings. We compared homepage layouts using the same course material and completed one teaching week before expanding the course ([800ed14](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/800ed14), [4fc9cde](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/4fc9cde)). I recommend three working documents to the tutor: the [goals file](docs/planning/implementation-goals.md) states what must be ready at my five review points; [implementation research](docs/IMPLEMENTATION-RESEARCH.md) records sources and choices; and [process evidence](docs/PROCESS-EVIDENCE.md) connects important problems to fixes and commits. I required these to stay current so the next task could use earlier decisions. PLAN.md recorded the next task, completed checks and choices still open ([c14d959...8d518f9](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/compare/c14d959...8d518f9)).

One important correction began when I restated that SAO should be taught as events in the course’s world. Review found that Week 2 still compared publicity and release dates. We revised the plan and CLAUDE.md before changing the readings, activity, slides and assessment together. Students now compare accounts of events and cite specific paragraphs, with the underlying works identified in credits. The harness now requires preparation and classroom activity to connect to assessment. That gave the historical viewpoint a practical role in what students do ([1c27051...9741b89](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/compare/1c27051...9741b89)).

I used comparison again when this account sounded too abstract. Two rounds used the same facts and criteria, fresh reviewers, anonymous labels and reversed reading order. I asked for the strongest supported parts to be combined; the agent checked reviewer concerns against commits. The resulting writing rule asks for actual requests, observations and changes. Tests protect details such as reading order and cross-week links; I kept the judgement of voice, appeal and course coherence at my review points ([9bc8a25](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/9bc8a25)).
