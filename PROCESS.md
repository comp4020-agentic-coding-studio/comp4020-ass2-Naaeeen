# Process overview

I think a good AI agent session needs a solid working framework, so research into agent practices and CLAUDE.md came first. Sword Art Online first drew me to computing. I wanted After Aincrad, a history course set in 2035, to make its events understandable to newcomers. Before building content, I asked Codex to research OpenAI and Anthropic guidance, studies of instruction files and practitioner methods. The sources, report, candidate instructions and trial results are saved in [the harness research folder](docs/harness-research/README.md). My starting point was the Crit 5 instructions that Claude had adapted during setup ([0b50b24](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/0b50b24)).

The “rules” we compared were the directions in CLAUDE.md: which files the agent should read, when it should plan and how it should check its work. Codex drafted revisions from the research and compared them with the original on small repository tasks. Across 18 scored runs, each pair started from matching project copies; only the CLAUDE.md version differed. The model and settings stayed fixed. We kept browser checks, added independent review, and told the agent to plan uncertain changes and read only relevant files. We also removed duplicate build instructions. The chosen practices went into CLAUDE.md, which I required the agent to follow. AGENTS.md directs Codex to read it before editing ([2b885c8](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/2b885c8)).

The evaluation checked behaviour as well as code: preserving existing edits, leaving files untouched on read-only tasks, and reporting which checks actually ran. We fixed these criteria before comparing outputs and kept the judging code outside the trial copies, checking it for changes. All 18 results passed its automatic checks. A separate agent reviewed outputs without their version labels and spotted a false pass: text that looked like a link counted as a link even though nothing was clickable. The main agent reproduced it, then replaced the text search with a check of real HTML links. That passed 31 valid and invalid cases ([785b1ce](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/785b1ce)).

Implementation followed the same loop: research a choice, plan it, build a small part, compare and review the result, then update the next task’s instructions. Agents owned separate teaching, source, interface and slide files; the main agent checked their findings. We compared homepage layouts using the same course material and completed one teaching week before expanding the course ([800ed14](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/800ed14), [4fc9cde](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/4fc9cde)). I recommend three working documents to the tutor: the [goals file](docs/planning/implementation-goals.md) requires ongoing research, A/B comparisons, verified subagent feedback, browser checks, CLAUDE.md updates and five human checkpoints; [implementation research](docs/IMPLEMENTATION-RESEARCH.md) records sources and choices; and [process evidence](docs/PROCESS-EVIDENCE.md) connects important problems to fixes and commits. I required the agent to follow these goals and keep the records current. PLAN.md recorded the next task, completed checks and choices still open ([c14d959...8d518f9](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/compare/c14d959...8d518f9)).

I asked for another redesign when the categories made it hard to see where learning began. The agent researched the structure before implementing “Start here” and a weekly plan: what to read before class, when and where to meet, and what to do afterwards. Atlas, slides, case files and assessments kept direct links. On a phone, the week selector was still below a long introduction, so the agent moved it into the first screen. CLAUDE.md gained a rule to check both a newcomer’s first action and a returning student’s week selection ([17ef14d](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/17ef14d), [9741b89](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/9741b89)).

I also rejected the first Aincrad model as unlike the original. Codex checked official artwork and a fan model, then rebuilt its dense, continuous floors. CLAUDE.md gained a rule to check visual references before review. The agent tested pause, reduced motion and the static fallback on desktop and phone; resemblance and course appeal remained my judgement ([8d518f9](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/8d518f9), [06ce955](https://github.com/comp4020-agentic-coding-studio/comp4020-ass2-Naaeeen/commit/06ce955)).
