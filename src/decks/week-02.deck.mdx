Which passage supports this revision?

What evidence would test it further?

<nav className="deck-nav" aria-label="Slide 6 navigation"><a href="#/claim">Previous</a><span>6 / 10</span><a href="#/comparison">Next</a></nav>

## Whose experience sets the starting point?

- Find one shared detail.
- Name a difference in emphasis.
- Explain why that difference matters.

An omission is a question to investigate.

<nav className="deck-nav" aria-label="Slide 7 navigation"><a href="#/revision">Previous</a><span>7 / 10</span><a href="#/choices">Next</a></nav>

```notes
Ask students to compare the texts directly. The absence of a detail in a short synopsis does not establish that it never occurred. Keep each detail attached to its adaptation. The aim is an explanation of a difference, not a contest to choose the one true account.
```
